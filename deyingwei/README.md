## 五、标准服务流程

① **上门检测**：接到报修后，技师按约定时间上门，对故障设备进行系统性检测，定位问题根源，而非凭经验草率下结论。

② **透明报价**：检测完成后，向客户说明故障原因、所需配件与对应费用，先沟通、后维修，拒绝未经确认的增项，让客户在动手前清楚花在哪里。

③ **维修 / 更换**：经客户确认后，使用原厂可溯源配件进行维修或更换；对确需整机更换的场景，提供对应品类产品销售，完成从"修"到"换"的闭环。

④ **质保交付**：维修或更换完成后，对关键步骤留痕，向客户说明使用与保养注意事项，并提供相应质保，让服务在交付后依然有保障。

这一流程兼顾了处置效率与客户知情权，特别适合对维修透明度与售后保障要求较高的家庭与商业客户。
